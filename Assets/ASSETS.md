# UI illustrations

The four added SVG files are small, locally authored vector approximations for
the HW1012 screen-cloning exercise. They contain no downloaded artwork and do
not embed or crop `References/settings-reference.png`.

- `DeviceWallpaper.svg`: an abstract blue folded illustration inspired by the device preview.
- `MicrosoftLogo.svg`: four colored squares representing the Microsoft mark.
- `Microsoft365Apps.svg`: simplified app illustrations; these are not the exact official 3D icons.
- `OneDriveLogo.svg`: a simplified blue cloud illustration.

Microsoft, OneDrive, and the app names are trademarks of their respective owners.
The illustrations are educational representations, not an assertion of affiliation.
Existing application logos and splash images are unchanged Visual Studio template assets.
